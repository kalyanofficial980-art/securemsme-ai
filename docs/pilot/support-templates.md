# Support Templates

Use these templates for first pilot customers.

## First outreach

Hi [Name],

I am running a private pilot for SecureMSME AI, a defensive website security-readiness platform for Indian MSMEs.

We check public website security basics, visible risk signals, and provide a simple report with fix priorities.

This is authorized, safe, and non-destructive. We do not test passwords, OTPs, login bypass, admin bypass, payment mutation, or destructive methods.

Would you like a pilot review for your website?

## Authorization request

Hi [Name],

Before review, please confirm:

1. You own or manage this website.
2. You authorize a safe, non-destructive review.
3. The review is limited to public website checks unless separately approved.
4. You understand this is not a complete security guarantee or legal certification.

Reply with:

I authorize SecureMSME AI to perform a safe, non-destructive security-readiness review of [website URL].

## Pilot accepted

Thanks [Name],

Your pilot review is accepted.

Next steps:

1. Confirm scope.
2. Run safe checks.
3. Manually review findings.
4. Send report and fix roadmap.
5. Retest after fixes if required.

Please do not send passwords, OTPs, private keys, payment data, API tokens, or production secrets.

## Report delivery

Hi [Name],

Your SecureMSME AI pilot report is ready.

Included:

- Risk summary
- Evidence-backed observations
- Fix priorities
- Retest checklist
- Security-readiness notes

Please review and share feedback.

Hi [Name],

This request is outside pilot scope.

For safety, we cannot perform password guessing, login bypass, OTP bypass, payment mutation, denial-of-service testing, exploit execution, third-party testing without permission, or customer data extraction.

We can continue with safe public website checks.
