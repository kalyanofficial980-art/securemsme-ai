# SecureMSME AI Customer Pilot Pack

Status: Private pilot ready

This folder contains documents for running the first 5 SecureMSME AI pilot customers.

SecureMSME AI is for defensive and authorized website security-readiness review only.

## Pilot rules

- Scan only customer-owned or explicitly authorized websites.
- Do not test third-party systems without written permission.
- Do not request passwords, OTPs, private keys, API tokens, payment data, or production secrets.
- Do not run destructive testing, brute force, denial-of-service, login bypass, payment mutation, or exploit execution.
- Use evidence-based report wording.
- Manual billing requires human review.

- customer-onboarding.md

## Pilot flow

1. Contact customer.
2. Collect website and business details.
3. Get scan authorization.
4. Add website to SecureMSME AI.
5. Run safe checks.
6. Manually review report.
7. Send report and fix roadmap.
8. Collect feedback and testimonial.
9. Discuss paid conversion.
