## Pilot scope

Allowed checks:

- Public website review
- Security header observations
- HTTPS/TLS observations
- Public link and page discovery
- Basic exposure review
- DPDP/security-readiness signals
- Report and fix roadmap
- Retest after fixes

Not allowed:

- Password guessing
- OTP testing
- Login bypass
- Admin bypass
- Payment/order mutation
- Exploit execution
- Destructive testing
- Denial-of-service testing
- Customer data extraction
- Third-party testing without permission

## Customer expectation

SecureMSME AI gives a defensive security-readiness review. It does not guarantee complete security, legal certification, or complete vulnerability coverage.
