## Scope allowed

I authorize SecureMSME AI to perform safe, non-destructive checks on public website pages and visible security configuration signals.

Allowed:

- Public page review
- Security header checks
- HTTPS/TLS observations
- Public link discovery
- Basic website exposure review
- Evidence-based report generation
- Fix-priority roadmap
- Retest after fixes

Not allowed unless separately approved:

- Authenticated testing
- Admin panel testing
- Payment/order flow testing
- API authenticated testing
- Third-party vendor systems
- Cloud/server console testing

Never allowed in pilot:

- Brute force
- Password guessing
- OTP bypass
- Login bypass
- Exploit execution
- Denial-of-service testing
- Malware
- Customer data extraction
- Destructive testing
- Unauthorized third-party scanning

## Safety notice

SecureMSME AI will not ask for passwords, OTPs, private keys, API tokens, card details, UPI PINs, or production secrets.
